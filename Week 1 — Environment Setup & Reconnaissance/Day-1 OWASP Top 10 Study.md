# Day 1 - OWASP Top 10 Study
##Objective
The first day focused on understanding the OWASP Top 10 web application security risks and their impact on real-world applications.

## Topics Studied
The following OWASP Top 10 categories were studied:

### OWASP ID	Vulnerability
A01	Broken Access Control
A02	Cryptographic Failures
A03	Injection
A04	Insecure Design
A05	Security Misconfiguration
A06	Vulnerable and Outdated Components
A07	Identification and Authentication Failures
A08	Software and Data Integrity Failures
A09	Security Logging and Monitoring Failures
A10	Server-Side Request Forgery (SSRF)

## Learning Objectives
### The study focused on:
•	web application attack surfaces
•	authentication and authorization flaws
•	insecure input handling
•	injection attacks
•	browser-based attacks
•	reconnaissance methodologies
•	exploitation workflow
