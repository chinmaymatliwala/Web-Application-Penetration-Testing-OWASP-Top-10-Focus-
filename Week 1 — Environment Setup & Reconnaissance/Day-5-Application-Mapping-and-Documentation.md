# Day 5 - Application Mapping & Security Documentation

## Objective
### Document reconnaissance findings and prepare for detailed vulnerability exploitation in Week 2.

## Activities Performed
- mapped application endpoints
- documented authentication flow
- recorded suspicious behavior
- organized reconnaissance notes
- collected evidence screenshots
- prepared proof-of-concept workflow

## Methodology Followed
### The testing process followed:
- OWASP Testing Guide
- PTES Methodology

### Penetration Testing Phases
1. Reconnaissance
2. Information Gathering
3. Vulnerability Identification
4. Exploitation
5. Risk Analysis
6. Reporting
7. Remediation

## Initial Vulnerability Indicators
### During Week 1, the following potential weaknesses were identified:
- Observation	Possible Vulnerability
- Error disclosure	Security Misconfiguration
- Route exposure	Broken Access Control
- Parameter reflection	DOM-Based XSS
- Weak validation	Injection/Input Validation
- Search manipulation	SQL Injection indicators
