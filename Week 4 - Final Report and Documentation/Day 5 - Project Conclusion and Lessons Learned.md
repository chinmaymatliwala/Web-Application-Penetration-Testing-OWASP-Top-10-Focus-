# Day 5 - Project Conclusion and Lessons Learned

This project involved performing web application penetration testing against OWASP Juice Shop using the OWASP Top 10 framework.

Activities included:

* Reconnaissance
* Vulnerability Discovery
* Exploitation
* Documentation
* Risk Assessment
* Remediation Planning
